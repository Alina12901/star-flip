# 星垂 · 卡面翻转（手机）

给 SillyTavern 手机端角色列表加「翻面」：正面是封面，点一下翻过来，看角色小传预览，最下面一颗「进入聊天」。

只在你用手机宽度（≤800px）、并且当前主题把角色列表排成相册网格时接管；换主题、或用电脑看，自动退回原来的角色卡。

## 安装（一条链接）

酒馆 → **扩展** → **安装扩展（Install extension）** → 粘贴：

```
https://github.com/Alina12901/star-flip
```

点安装，然后刷新页面。装好之后这个面板里的「更新」按钮也能用，以后有新版点一下就行。

不想走 GitHub 的话，也可以下载 [整包 zip](https://github.com/Alina12901/star-flip/releases) 用酒馆助手导入脚本，或把 `star-flip` 文件夹丢进 `data/<用户>/extensions/`。

## 先看效果

[点这里翻几张卡试试](https://alina12901.github.io/star-flip/)（10 张示例卡，单文件，手机上也能开）

## 它什么样

- **正面**：原图封面、金色衬线名字、作者备注一行、右上角一枚「翻开」
- **翻开**：760ms 的 3D 翻面，同时只开一张；再点卡面翻回去，Esc 也能合上
- **背面**：米色相纸质感，`角 色 小 传` 抬头、`NO.xx` 编号、正文，最下面墨色胶囊「进入聊天」
- **封面**：先缩略图占位，进视野后换原图（并发 2 张，慢网或省流量模式自动只用缩略图）

小传不是把 `description` 整段塞进去，而是抽人话：散文取开头 1～3 句；纯字段表（YAML / `<info>` / 世界观）挑「性格特点 / 身份 / 年龄 / 核心驱动力」这类键拼成两三句；都没有就写「这一页还没有写下小传。」正文按卡片实际高度取整数行截断，窄屏也不会出现半截被切开的字。

## 门控条件

三个都成立才接管，否则原样还回去：

```js
matchMedia('(max-width: 800px)')                 // 手机
getComputedStyle(block).display === 'grid'       // 主题把列表排成网格
getComputedStyle(card).aspectRatio !== 'auto'    // 卡片有固定比例
```

## 兼容

SillyTavern 1.18.0 实测（38 张角色卡逐张验收）。依赖主题提供网格布局；原生默认主题是 flex 列表，不会触发，需要在酒馆设置里套用相册类主题（例如「星垂·手机相册」）。
